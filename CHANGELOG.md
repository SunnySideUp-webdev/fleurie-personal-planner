# Changelog

Notable changes to Fleurie Personal Planner are documented here. This project follows the structure of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Installable PWA manifest with standard, adaptive, and Apple home-screen icons.
- Production-only service worker with offline access to previously opened pages and static resources.
- Third-party dependency license notice.
- GitHub Pages static-export workflow and portfolio screenshots.
- User-facing warning when browser storage is full and the latest changes cannot be persisted.

### Changed

- Updated copyright attribution to Sharon (Sunny) Consuegra.
- Recorded ownership and public portfolio permission for the visual assets.
- Added repository-subpath support for public images, decorative backgrounds, application icons, navigation, and PWA scope.
- Refined the mobile Today header so the date and Add action do not overlap.

### Planned

- Add a user-controlled data backup and restore flow.
- Add automated tests and linting.

## [1.0.0] - 2026-10-10

### Added

- Integrated Today dashboard.
- Planner tasks, reminders, goals, and calendar.
- Habit, mood, routine, workout, and statistics experiences.
- Closet, outfit canvas, Today assignment, and Lookbook previews.
- Expense, budget, and savings tracking.
- Journal entries with movable photos and stickers.
- Shopping, wishlist, personal lists, and notes.
- Browser-local persistence across feature areas.
- Fleurie vintage floral branding and decorative compositions.

### Fixed

- Kept quick-journal submissions from generating duplicate entries.
- Restored multi-color category segments in the monthly spending chart.
- Synced dated or explicitly assigned outfits with Today.
- Rendered saved outfit placements and layers consistently in Today and Lookbook.
- Displayed the favorite savings goal image on Today.
